# Code

Images are read from `../DATA/` (course data, not in the repo).

| Notebook                                 | Topic                                                                      |
| ---------------------------------------- | -------------------------------------------------------------------------- |
| `02-01-numpy-arrays.ipynb`               | NumPy basics: creation, random, max/argmax, reshape, slicing, view vs copy |
| `02-02-images-as-numpy-arrays.ipynb`     | PIL → NumPy, image shape, color channels, isolating red                    |
| `02-03-numpy-and-image-assessment.ipynb` | Section 2 assessment: isolate the blue channel                             |
