# image-processing-notes

My study notes for **Image Processing and Computer Vision** (an Obsidian vault): a 12-week path from classical OpenCV to Vision Transformers, CLIP and diffusion models.

## Structure
| Folder | Content |
|---|---|
| [`00 - Study Plan.md`](00%20-%20Study%20Plan.md) | the 12-week plan |
| [`Weeks/`](Weeks/) | one note per week: goal, notes, concepts, code, questions |
| [`Concepts/`](Concepts/) | one note per concept, with code and comparison figures |
| [`Code/`](Code/) | Jupyter notebooks, named `<section>-<lesson>-<topic>.ipynb` |
| [`Images/`](Images/) | figures generated from the notebooks, used in the notes |
| [`Templates/`](Templates/) | Obsidian templates for weekly and concept notes |

## Progress
- ✅ Section 1 · Course Overview
- ✅ Section 2 · NumPy and Image Basics → [NumPy Arrays](Concepts/NumPy%20Arrays.md), [Image as a NumPy Array](Concepts/Image%20as%20a%20NumPy%20Array.md), [RGB Color Channels](Concepts/RGB%20Color%20Channels.md), [Colormaps](Concepts/Colormaps.md)
- ⏳ Section 3 · Image Basics with OpenCV

## Running the notebooks
The notebooks read images from `DATA/` (e.g. `../DATA/00-puppy.jpg`). That folder is the course's data and is **not included** in this repo; download it from the course and put it in the repo root as `DATA/`.
